# Submission checklist

## 48 hours before

- [ ] Re-read official brief and FAQ; record date/time.
- [ ] Freeze MVP and dependency changes.
- [ ] Run full automated suite and AI evals.
- [ ] Complete manual accessibility and slow-network checks.
- [ ] Verify synthetic-data markings in every fixture.
- [ ] Verify third-party notices and licence compatibility.
- [ ] Confirm no official logos/emblems or endorsement language.
- [ ] Confirm all integrations are visibly labeled mock.
- [ ] Scan repository/build/logs for secrets and real identifiers.
- [ ] Test reset, seed IDs, reviewer entry, and AI-off fallback.

## Public demo

- [ ] URL works in a signed-out private browser.
- [ ] No password, access request, geographic restriction, or expiring preview.
- [ ] HTTPS and safe headers verified.
- [ ] Mobile and desktop primary flow each succeed twice.
- [ ] The citizen submission genuinely appears in reviewer queue.
- [ ] Reviewer decision genuinely updates citizen timeline.
- [ ] Optional integrations failing do not block the primary path.
- [ ] No developer console errors on the demo path.
- [ ] Demo seed/reset cannot affect external systems.

## Video

- [ ] Duration no more than two minutes.
- [ ] Captions included and checked.
- [ ] Synthetic/mock/independent status visible.
- [ ] Shows the complete resolution loop, not only landing-page animation.
- [ ] Every shown feature works in the deployed build.
- [ ] No real data, secrets, private tabs, or personal notifications.
- [ ] Final export plays correctly on a second device.

## Write-up

- [ ] One-sentence problem and audience.
- [ ] Official scale and Rule 167 citations.
- [ ] Clear before/after service journey.
- [ ] Why this differs from payment aggregators and cosmetic redesigns.
- [ ] Implemented vs mocked vs planned table.
- [ ] Architecture, accessibility, safety, and AI boundary.
- [ ] Open-source/external-tool disclosures.
- [ ] Independent-prototype disclaimer.
- [ ] Public demo URL and optional repository link verified.

## Final day

- [ ] Re-check current deadline/time zone and finale details.
- [ ] Re-run clean public demo on separate network.
- [ ] Save final build hash/version and test evidence.
- [ ] Submit with buffer; do not wait for the last minutes.
- [ ] Save confirmation, submitted text, URLs, and timestamps.
